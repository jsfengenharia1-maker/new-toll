## 1. Aba de módulo "Fundações" escopada
A faixa também terá uma aba "Fundações" (`role=tab`); `getByRole('tab', { name: 'Fundações', exact: true })` passa a resolver em 2 elementos. Em `e2e/flows.mjs`, nas duas linhas que têm esse seletor (hoje 1442 e 2335):
```js
await page.getByRole('tab', { name: 'Fundações', exact: true }).click();
```
trocar por
```js
await page.getByRole('tablist', { name: 'Módulo' }).getByRole('tab', { name: 'Fundações', exact: true }).click();
```
(O `tablist` de módulo já tem `aria-label="Módulo"` hoje; a D2 mantém.) Opcional e recomendado: o mesmo escopo nas 73 chamadas de `getByRole('tab', { name: 'Edifício', exact: true })`, por `sed -i "s/page.getByRole('tab', { name: 'Edifício', exact: true })/page.getByRole('tablist', { name: 'Módulo' }).getByRole('tab', { name: 'Edifício', exact: true })/g" e2e/flows.mjs`.

## 2. Altura da janela dos fluxos
A faixa de comandos e a linha das abas de módulo somam 151 px de altura (a faixa recolhida, 71 px). Com o viewport de 900 px o canvas cai ao mínimo de 240 px, e fluxos por coordenada (FU3) e o painel das lajes (R7e) falham. Em `e2e/run.mjs`, em `newPage`:
```js
viewport: { width: 1400, height: 900 }
```
para
```js
viewport: { width: 1400, height: 1080 }
```
Não mexer em `telaDe` nem em `reenquadrarAte`: continuam servindo (reenquadram até o ponto cair dentro do canvas).
