# L4 — cartão 06: Fluxo e2e `L4`

Classe: Haiku (interface sobre núcleo pronto; código validado).

## Arquivos
- `e2e/flows.mjs`: novo fluxo `L4: cópia entre grupos, união, áreas, ajuda F1, atalhos configuráveis, guia rápido, referências e memorial` (copia Tipo para Cobertura, desfaz e refaz em um passo, F1 liga e Esc desliga, botão de ajuda e botão direito, atalhos configuráveis com persistência, guia, mover referência por dois cliques, memorial)

## Núcleo usado (já existe)
Sem núcleo novo.

## Aplicação
`git apply docs/cartoes/L4/patches/06-e2e.patch` (ou aplique o bloco `diff` abaixo, trecho a trecho).

## Verificação
- `npm run e2e -- L4`
- `npm run e2e -- planta`
- `npx tsc -b`

## Rótulos e regras
Regras do fluxo: `{ exact: true }` em nomes de botões, checks e papéis; `NumField` e `Select` por regex ancorada no início (`/^Grupo de origem/`), porque o rótulo envolve o campo. Rótulos únicos: não repita o texto de outro botão da tela (o e2e usa `{ exact: true }`). Sem botões novos na barra da planta.
