## Núcleo usado (tudo já existe; assinaturas conferidas)
De `../../core/building/paredesLista` (puras, testadas em `paredesComandos.test.ts`):
- `linhasPanos(r: ResultadoParedeDim): LinhaPano[]` — `LinhaPano { chave, lado, trecho, pavimento, lance, pano, panos, intervalo, necessaria, vertical, horizontal, cumprimento, origem: 'bloqueada' | 'calculada' | 'sem armadura', situacao, status: 'ok' | 'fail', vert: {phi, s} | null, hor: {phi, s} | null }`.
- `linhasPontos(r): { trecho, lance, descricao, faixa, adicional }[]`, `linhasEmendas(d: DetalheParede | undefined): { chave, pavimento, trecho, acima, tipo, phi, minimo, adotada, origem }[]`, `linhasLadosCurtos(r): { lado, trecho, lance, comprimento, barras, estribo, utilizacao, situacao }[]`, `mensagensDe(r, d?): { local, texto }[]`, `resumoCartao(r): { armadura, cumprimentoMin, situacao, status, panos }`.
- `comandoDe(tipo: 'parede' | 'pilarParede'): string` (`'parede.armadura'` ou `'pilarParede.armadura'`) e `valoresIniciais(l: Pick<LinhaPano, 'vert' | 'hor'> | undefined): { vPhi: number; vS: number; hPhi: number; hS: number }` (espaçamentos em cm; sem malha, φ8 c/15). Exemplos conferidos no teste: `valoresIniciais({ vert: { phi: 12.5, s: 0.15 }, hor: { phi: 6.3, s: 0.2 } })` = `{ vPhi: 12.5, vS: 15, hPhi: 6.3, hS: 20 }`.
- `paramsBloquearPano(id, l: Pick<LinhaPano, 'lado' | 'pavimento' | 'pano'>, vert: { phi: number; sCm: number }, hor: { phi: number; sCm: number }): Record<string, unknown>` (converte cm em m) e `paramsEmendas(id, pavimento, tracaoCm?, compressaoCm?): Record<string, unknown>`.
- De `../../core/building/paredesArmadura`: `BITOLAS_PAREDE` (`number[]`: 6.3, 8, 10, 12.5, 16, 20, 25).
- De `./Armadura` (já existe): `executarERecalcular(nome: string, params: Record<string, unknown>): Promise<boolean>` — executa o comando e atualiza o dimensionamento (rearma sem refazer a análise; `parede.redimensionar` refaz a análise).
- Dados: `useBuilding((s) => s.dim)` é `DimEdificio | null` com `armaduraParedes?: ResultadoParedeDim[]` e `detalhesParedes?: DetalheParede[]`; `useBuilding((s) => s.sessao.modelo)` é o `BuildingModel`.
- Comandos (todos `mcp: false`): `parede.armadura`, `pilarParede.armadura` (`{ id, lado?, pavimento?, pano?, vert?, hor?, emendas?, limparEmendas? }`), `armadura.desbloquear { ids }`, `parede.redimensionar { id, pavimento?, espessura (m) }`.
- Para a espessura (só parede): `ppDaParede(w)` de `../../core/building/paredesBase`, `lancesDoPP` e `ladosDoPP` de `../../core/building/pilarParede` (`ladosDoPP(b, pp)[0].esp(pavimentoId).t` é a espessura total em m).

## Layout e rótulos exatos de `ArmaduraDaParede({ id, tipo }: { id: string; tipo: 'parede' | 'pilarParede' })`
Raiz `<div data-pw-armadura={id}>`. `const dim = useBuilding((s) => s.dim)`, `const b = useBuilding((s) => s.sessao.modelo)`, `const r = dim?.armaduraParedes?.find((x) => x.id === id)`, `const det = dim?.detalhesParedes?.find((x) => x.id === id)`. Sem `r`: `return <Hint>Calcule o dimensionamento para ver a armadura.</Hint>;` (todos os hooks `useState` antes do `return` antecipado).
1. `<h4>Armadura por pano</h4>` e `<p className="small" data-pw-situacao>` com `<Pill tone={rc.status === 'ok' ? 'ok' : 'bad'}>{rc.situacao}</Pill>` seguido de ` {rc.panos} pano(s) · cumprimento mínimo {rc.cumprimentoMin} · {rc.armadura}` (`rc = resumoCartao(r)`).
2. Tabela `data-pw-panos` com as colunas **Trecho**, **Lance**, **Pano**, **s (m)**, **Necessária V / H (cm²/m)**, **Vertical**, **Horizontal**, **Cumprimento**, **Origem**, **Situação**; uma `<tr data-chave={l.chave} aria-selected={sel === l.chave} className={l.status === 'fail' ? 'bad' : undefined} onClick={() => setSel(l.chave)}>` por `linhasPanos(r)`; células: `l.trecho`, `l.lance`, `l.pano + 1`, `l.intervalo`, `l.necessaria`, `l.vertical`, `l.horizontal`, `l.cumprimento`, `l.origem`, `l.situacao`. A linha selecionada é `sel` (estado `string`, padrão a `chave` da primeira linha).
3. Abaixo da tabela, editor `<div className="row wrap" data-pw-editor-malha>`: `Select label="φ vertical"` (opções `BITOLAS_PAREDE.map((p) => ({ v: p, label: String(p).replace('.', ',') }))`), `NumField label="s vertical" unit="cm" width={90}`, `Select label="φ horizontal"`, `NumField label="s horizontal" unit="cm" width={90}`, `Button` **"Bloquear malha"** e `Button` **"Desbloquear"**.
   - Estado `edit: { chave: string; vPhi: number; vS: number; hPhi: number; hS: number } | null`. Valores mostrados: `edit?.chave === linhaSel.chave ? edit : { chave: linhaSel.chave, ...valoresIniciais(linhaSel) }`; cada campo grava `setEdit({ ...atual, campo: valor })`.
   - **Bloquear malha**: `executarERecalcular(comandoDe(tipo), paramsBloquearPano(id, linhaSel, { phi: vPhi, sCm: vS }, { phi: hPhi, sCm: hS }))`.
   - **Desbloquear**: `executarERecalcular('armadura.desbloquear', { ids: [id] })`.
   - `Hint`: "Malhas iguais nas duas faces. A malha bloqueada é verificada, não redimensionada; abaixo do fator de cumprimento exigido (opção 'Paredes: fator de cumprimento') o pano é reprovado."
4. `<details data-pw-pontos>` com `<summary>Pontos que não atendem e reforços locais ({n})</summary>` (`n = linhasPontos(r).length`) e tabela `data-pw-pontos-lista` com **Trecho**, **Lance**, **Item**, **Faixa**, **Armadura adicional**. Sem linhas: `<p className="muted">Todos os pontos atendem com a malha uniforme.</p>`.
5. Só `tipo === 'parede'`: `<h4>Espessura</h4>` e `<div className="row wrap" data-pw-espessura>` com `Select label="Lance da espessura"` (opções: `lancesDoPP(b, ppDaParede(w)).map((l) => ({ v: l.id, label: l.nome }))`, `w = b.paredes?.find((q) => q.id === id)`; padrão o primeiro), `NumField label="Espessura" unit="cm" width={90}` (valor inicial `+(ladosDoPP(b, ppDaParede(w))[0].esp(lance).t * 100).toFixed(1)`; estado local `espCm: number | null`, `null` = a do modelo) e `Button` **"Aplicar espessura"** → `executarERecalcular('parede.redimensionar', { id, pavimento: lance, espessura: +(espCm / 100).toFixed(4) })`. `Hint`: "Mudar a espessura refaz a análise."
6. `<h4>Emendas por traspasse</h4>`; se `linhasEmendas(det)` vazio: `<p className="muted">Sem emendas (parede de um lance só).</p>`; senão tabela `data-pw-emendas` com **Trecho**, **Acima de**, **Tipo**, **φ**, **Mínimo (cm)**, **Adotada (cm)**, **Origem** e o editor `<div className="row wrap" data-pw-editor-emendas>`: `Select label="Pavimento da emenda"` (pavimentos distintos de `linhasEmendas(det)`, valor `pavimento`, rótulo `acima`; estado `pavEm`, padrão o primeiro), `NumField label="Tração" unit="cm" width={90}`, `NumField label="Compressão" unit="cm" width={90}` (estados `trac`, `comp`: `number | null`; `null` = adotada da primeira emenda do pavimento do tipo correspondente, `Number(adotada.replace(',', '.'))`; se o pavimento só tem uma emenda, o campo do outro tipo começa vazio = 0 e só é enviado se editado), `Button` **"Aplicar emendas"** → `executarERecalcular(comandoDe(tipo), paramsEmendas(id, pavEm, trac ?? undefined, comp ?? undefined))` e `Button` **"Voltar às calculadas"** → `executarERecalcular(comandoDe(tipo), { id, limparEmendas: true })`.
7. Se `linhasLadosCurtos(r).length`: `<h4>Trechos curtos (dimensionados como pilar)</h4>` e tabela `data-pw-lados-curtos` com **Trecho**, **Lance**, **Comprimento (cm)**, **Barras**, **Estribo**, **Utilização**, **Situação**.
8. `<h4>Mensagens</h4>` e `<ul data-pw-mensagens>` com `<li key={i}><b>{m.local}</b>: {m.texto}</li>` por `mensagensDe(r, det)`; vazio: `<p className="muted">Sem mensagens.</p>`.
