## (A) Armadura das aberturas — `AberturasArmadura`
Núcleo (de `../../core/building/paredesLista`): `linhasAberturas(res: ResultadoParedeDim[]): LinhaAbertura[]` (`LinhaAbertura { id, tipo: 'porta' | 'janela', parede, lance, dimensoes, necessaria, verga, estribo, peitoril, montante, canto, origem: 'calculada' | 'bloqueada' | 'padrao', situacao, status: 'ok' | 'fail', armadura: ArmaduraAbertura }`), `formDaArmadura(a: ArmaduraAbertura): FormAbertura`, `armaduraDoForm(f: FormAbertura, tipo: 'porta' | 'janela'): ArmaduraAbertura`, `aberturasDoMesmoTipo(b: BuildingModel, id: string): string[]`; `FormAbertura { vergaN, vergaPhi, estriboPhi, estriboSCm, peitorilN, peitorilPhi, montanteN, montantePhi, cantoN, cantoPhi }`. Comando `abertura.armadura` (`mcp: false`): `{ acao: 'editar', abertura, armadura }`, `{ acao: 'copiar', de, para: string[] }`, `{ acao: 'padrao', tipo, armadura }`, `{ acao: 'limpar', abertura }` ou `{ acao: 'limpar', tipo }`. `executarERecalcular` de `./Armadura`. `BITOLAS_PAREDE` de `../../core/building/paredesArmadura`. Dados: `dim?.armaduraParedes`, `b.paredes`, `b.aberturasPadrao`.

Layout: `<div data-pw-aberturas-arm>`; `<h4>Armadura das aberturas</h4>`. Só as linhas desta parede: `linhasAberturas(dim.armaduraParedes ?? []).filter((l) => w.aberturas?.some((a) => a.id === l.id))` (`w = b.paredes?.find((q) => q.id === id)`). Sem `dim`: `<Hint>Calcule o dimensionamento para ver a armadura das aberturas.</Hint>`.
1. Tabela `data-pw-aberturas-arm-lista` com **Abertura** (`tipo` e `dimensoes`), **Lance**, **Necessária (verga / peitoril / montante)**, **Verga**, **Estribos**, **Peitoril**, **Montantes**, **Cantos**, **Origem**, **Situação**; `<tr data-id={l.id} aria-selected={sel === l.id} className={l.status === 'fail' ? 'bad' : undefined} onClick={() => setSel(l.id)}>`; `sel` padrão = id da primeira linha.
2. Editor `<div className="row wrap" data-pw-editor-abertura>` para a linha selecionada, com `NumField`/`Select` de `FormAbertura` (estado `form: FormAbertura | null`; `null` = `formDaArmadura(linhaSel.armadura)`; trocar de linha zera o estado — guarde `{ id, form }`): `NumField label="Verga n"`, `Select label="Verga φ"`, `Select label="Estribo φ"` (opções `5`, `6,3`, `8`, `10`), `NumField label="Estribo s" unit="cm"`, `NumField label="Peitoril n"` e `Select label="Peitoril φ"` (só em janela), `NumField label="Montante n"`, `Select label="Montante φ"`, `NumField label="Cantos n"`, `Select label="Cantos φ"`. Opções de φ: `[...BITOLAS_PAREDE, 32].map((p) => ({ v: p, label: String(p).replace('.', ',') }))` (estribo: só 5, 6.3, 8, 10).
3. Botões (cada um chama `executarERecalcular('abertura.armadura', …)`): **"Bloquear armadura da abertura"** `{ acao: 'editar', abertura: sel, armadura: armaduraDoForm(form, linhaSel.tipo) }`; **"Copiar para as de mesmo tipo"** `{ acao: 'copiar', de: sel, para: aberturasDoMesmoTipo(b, sel) }` (desabilitado se `aberturasDoMesmoTipo(b, sel)` for vazio ou a abertura selecionada não tiver armadura própria: `!w.aberturas?.find((a) => a.id === sel)?.armadura`); **"Definir como padrão do tipo"** `{ acao: 'padrao', tipo: linhaSel.tipo, armadura: armaduraDoForm(form, linhaSel.tipo) }`; **"Limpar armadura"** `{ acao: 'limpar', abertura: sel }`; **"Limpar padrão do tipo"** `{ acao: 'limpar', tipo: linhaSel.tipo }` (desabilitado sem `b.aberturasPadrao?.[linhaSel.tipo]`).
4. `<details data-pw-relatorio-abertura>` com `<summary>Relatório da abertura selecionada</summary>` e `<ul>` de quatro itens (texto livre com vírgula decimal, `fmt` = 2 casas): "Necessária: verga {x} cm², peitoril {y} cm², montantes {z} cm² (barras verticais interrompidas)." (de `ResultadoAbertura.necessaria`), "Adotada ({origem}): verga {linha.verga}, estribos {linha.estribo}, peitoril {linha.peitoril}, montantes {linha.montante}, cantos {linha.canto}.", "Cortante da verga: Vsd {Vsd} kN × VRd2 {VRd2} kN — {atende | não atende}." (de `ResultadoAbertura.cortanteVerga { Vsd, VRd2, ok }`, obtido de `dim.armaduraParedes.flatMap((x) => x.aberturas).find((a) => a.id === sel)`), e as mensagens da abertura (`mensagens`) ou "Sem mensagens.".
5. `Hint`: "Verga e peitoril pela tração N/2 + M/z integrada nos elementos da casca acima/abaixo da abertura; montantes = barras verticais interrompidas; a armadura bloqueada é verificada, não redimensionada. Premissa e1d-aberturas a confirmar."

## (B) Isovalores — `IsovaloresParede`
Núcleo: `campoTensaoLado(b, an, ladoId, comb: CombinacaoEd, comp: ComponenteTensao, face?: 1 | -1): CampoLado | null` e `campoDeslocamentoLado(b, an, ladoId, caso: string, comp: ComponenteDeslocamento): CampoLado | null` de `../../core/building/campoParede`; `CampoLado { tris: { v: [[s, z], [s, z], [s, z]]; valor: number; lance: string }[]; min; max; unidade: string; titulo: string }`; `ComponenteTensao = 'sigmaX' | 'sigmaY' | 'tauXY' | 'My' | 'Mx' | 'Qmax'`; `ComponenteDeslocamento = 'normal' | 'vertical' | 'alongo'`. De `../../core/building/paredesLista`: `faixaDoCampo(valor, min, max, faixas?): number` (0 a 10), `caixaDoCampo(c: CampoLado): { s0, z0, s1, z1 }`, `N_FAIXAS_ISO` (11). `combinacoesDoEstado(b, an, 'concreto')` de `../../core/building/combinacoes` (devolve `CombinacaoEd[]`; use as de `tipo === 'ELU'`). Dados: `useBuilding((s) => s.analise)` (`AnaliseEdificio | null`), `s.sessao.modelo`, `s.dim`. O id do lado é `${id}:${lado}` (ex. `pw_x:0`); lados em casca: `dim.armaduraParedes.find((x) => x.id === id).lados.filter((l) => l.modelo === 'casca')`, nome do lado = `l.nome`, índice = `l.lado`.

Layout: `<div data-pw-isovalores={id}>`; `<h4>Tensões e deslocamentos</h4>`; sem `analise` ou sem lados em casca: `<Hint>Calcule o dimensionamento para ver os mapas.</Hint>`. Linha de controles `<div className="row wrap">`:
- `Select label="Lado do mapa"` (um por lado em casca, `v` = índice do lado, `label` = nome, padrão o primeiro);
- `Seg` com `{ v: 'tensao', label: 'tensões' }` e `{ v: 'deslocamento', label: 'deslocamentos' }`;
- tensões: `Select label="Grandeza"` com `sigmaX` "σx (MPa)", `sigmaY` "σy (MPa)", `tauXY` "τxy (MPa)", `My` "My (kN·m/m)", `Mx` "Mx (kN·m/m)", `Qmax` "Q máx. (kN/m)"; `Select label="Combinação ELU"` (nomes das ELU, valor = nome); `Seg` face `{ v: '-1', label: 'face z−' }` e `{ v: '1', label: 'face z+' }` (só para σx, σy e τxy); campo = `campoTensaoLado(b, analise, `${id}:${lado}`, comb, grandeza, face)`;
- deslocamentos: `Select label="Caso"` (`analise.casos` e `analise.vento?.casos.map((c) => c.nome)`; rótulo = nome do caso em `b.casos` ou o próprio id) e `Select label="Componente"` com `normal` "normal ao plano", `vertical` "vertical", `alongo` "ao longo do eixo"; campo = `campoDeslocamentoLado(b, analise, ladoId, caso, componente)`.
Resultado `campo` (`null` → `<p className="muted">Sem resultado para este lado.</p>`):
- `<svg className="iso-svg" role="img" aria-label={campo.titulo} data-pw-iso-svg viewBox={`${cx.s0} ${-cx.z1} ${cx.s1 - cx.s0} ${cx.z1 - cx.z0}`} preserveAspectRatio="xMidYMid meet">` (`cx = caixaDoCampo(campo)`; o eixo z é invertido: ponto `s,-z`), com um `<polygon className={`iso iso-${faixaDoCampo(t.valor, campo.min, campo.max)}`} points={t.v.map((p) => `${p[0]},${-p[1]}`).join(' ')} key={i} />` por triângulo;
- legenda `<div className="iso-leg" data-pw-iso-leg>`: 11 `<span className={`iso-cel iso-${k}`} key={k} />` (k = 0 a 10) e o texto `mín. {fmt(campo.min)} · máx. {fmt(campo.max)} {campo.unidade} — {campo.titulo}` (`fmt` = 3 casas, vírgula decimal).
CSS em `global.css` (no primeiro `:root`): `--iso-0: #2b4ba8; --iso-1: #3f6fc4; --iso-2: #5c93d6; --iso-3: #86b6e2; --iso-4: #b3d4ea; --iso-5: #e3ece9; --iso-6: #f2dcb4; --iso-7: #eab883; --iso-8: #de8d5c; --iso-9: #c95a3c; --iso-10: #a02a2a;`. Classes (fora dos blocos de tema, junto das `.det-*`): `.iso-svg { width: 100%; max-height: 320px; background: var(--surface); }`, `.iso { stroke: var(--line); stroke-width: 0.5; vector-effect: non-scaling-stroke; }`, `.iso-leg { display: flex; align-items: center; gap: 2px; flex-wrap: wrap; }`, `.iso-cel { width: 18px; height: 10px; display: inline-block; }` e, para k de 0 a 10, `.iso-k { fill: var(--iso-k); background: var(--iso-k); }` (um por faixa; `fill` vale no SVG, `background` na legenda). `--surface` e `--line` já existem no primeiro `:root`.

## (C) Muros de arrimo — `MurosGrupo`
Núcleo: `linhasMuros(b: BuildingModel, muros: ResultadoMuroDim[] | undefined): LinhaMuro[]` de `../../core/building/paredesLista` (`LinhaMuro { id, nome, geometria, fsTombamento, fsDeslizamento, tensao, fuste, base, aco, situacao, status: 'ok' | 'fail' }`; `situacao` = `'calcule'` sem resultado); `b.murosArrimo?: MuroArrimoObra[]` (`{ id, nome, H, tTopo, tBase, B, ponta, hBase, solo: { gama, phi, metodo: 'repouso' | 'rankine' | 'coulomb', delta?, k? }, sobrecarga?, gamaConcreto?, atrito?, sigmaAdm?, fsTombamento?, fsDeslizamento? }`, `src/core/building/types.ts`); comandos `muro.arrimo` (sem `id` cria; com `id` substitui todos os campos) e `muro.remover { ids }`; `dim?.muros` (`ResultadoMuroDim[]` com `id`, `nome`, `estabilidade`, `fuste`, `base`, `barras`, `peso`, `status`, `mensagens`).

Layout (`Group title={`Muros de arrimo (${n})`} open={n > 0}`, `n = (b.murosArrimo ?? []).length`):
1. Formulário `<div className="row wrap" data-mu-form>`: `TextField label="Nome"` (padrão `MA{n+1}`), `NumField label="Altura do fuste" unit="m"` (3), `NumField label="Espessura no topo" unit="cm"` (20), `NumField label="Espessura na base do fuste" unit="cm"` (30), `NumField label="Largura da base" unit="m"` (2,6), `NumField label="Ponta" unit="m"` (0,5), `NumField label="Espessura da base" unit="cm"` (40), `NumField label="γ do solo" unit="kN/m³"` (18), `NumField label="φ do solo" unit="°"` (30), `Select label="Método do empuxo"` (`repouso` "repouso (K0)", `rankine` "Rankine", `coulomb` "Coulomb"; padrão `rankine`), `NumField label="Sobrecarga" unit="kN/m²"` (10), `OptNumField label="Atrito base-solo"` (vazio = tg(2φ/3)), `OptNumField label="σadm do solo" unit="kN/m²"` e `Button` **"Lançar muro"** → `executarERecalcular('muro.arrimo', { nome, H, tTopo: cm2m(...), tBase: cm2m(...), B, ponta, hBase: cm2m(...), solo: { gama, phi, metodo }, ...(sobrecarga ? { sobrecarga } : {}), ...(atrito !== undefined ? { atrito } : {}), ...(sigmaAdm !== undefined ? { sigmaAdm } : {}) })` com `cm2m = (v: number) => +(v / 100).toFixed(4)`. Estados locais (`useState`) para cada campo.
2. Tabela `data-mu-lista` (só se houver muros) com **Muro** (`<b>`), **Geometria**, **FS tombamento**, **FS deslizamento**, **Tensão máx. / mín.**, **Fuste**, **Base**, **Aço**, **Situação** (`<Pill tone={l.status === 'ok' ? 'ok' : 'bad'}>`; `calcule` com `tone="na"`), botão `ghost` `aria-label={`Remover ${l.nome}`}` texto **×** → `executarERecalcular('muro.remover', { ids: [l.id] })`. Linhas de `linhasMuros(b, dim?.muros)`; `className="bad"` quando `status === 'fail'`.
3. `Hint`: "Muro de arrimo em balanço isolado, por metro: estabilidade (tombamento, deslizamento, tensões) e armadura do fuste e da base. Premissas e1c-muro-arrimo e e1d-muro-arrimo a confirmar. Calcule o edifício para ver o resultado."
4. Mensagens do muro selecionado: ao clicar na linha, abaixo da tabela `<ul data-mu-mensagens>` com `dim?.muros?.find((m) => m.id === sel)?.mensagens` (um `<li>` por mensagem; vazio: "Sem mensagens.").
