- Janela: `linhasPanosAlv(r)` → `{ chave, lado, trecho, pavimento, lance, pano, panos, intervalo, esbeltez, utilizacao, cumprimento, vertical, horizontal, origem, governa, situacao, status }[]`; `linhasPontosAlv(r)` → `{ trecho, lance, ponto, area, limite, utilizacao, combinacao }[]`; `linhasLadosAlv(r)` → `{ trecho, lance, comprimento, esbeltez, utilizacao, combinacao, situacao }[]`; `linhasVergas(r)` → `{ id, tipo, lance, dimensoes, modular: 'sim' | 'não', necessaria, verga, contraverga, estribo, cortante, origem, situacao, status, armadura: ArmaduraVerga }[]`; `linhasQuantitativo(r)` → `{ lance, fiadas, inteiros, meios, cantos, canaletas, total, area }[]` (a última linha é o total, `lance: 'Total'`); `mensagensAlv(r)` → `{ local, texto }[]`; `linhasDesligamentos(al, parede?)` → `{ pilar, pavimento, laje, desligado }[]`; `linhasVigasMuro(al, parede?)` → `{ viga, papel, secao, armadura, situacao }[]`; `resumoCartaoAlv(r)` → `{ material, armada, cumprimentoMin, blocos, situacao, status, panos }`.
- Verga: `FormVerga { n; phi; estriboPhi; estriboSCm; contravergaN; contravergaPhi }`, `formDaVerga(a?: ArmaduraVerga): FormVerga`, `armaduraVergaDoForm(f, tipo: 'porta' | 'janela'): ArmaduraVerga`, `paramsVergaEditar(abertura: string, f, tipo): Record<string, unknown>`, `aberturasBlocosDoMesmoTipo(b, id): string[]`, `BITOLAS_ALV_VERTICAL`, `BITOLAS_ESTRIBO_VERGA = [5, 6.3, 8]`.
- Lançamento: `rotuloTipoParede(b, w): string`, `tiposDoTipoParede(b, 'alvenaria' | 'blocos'): TipoAlvenaria[]`, `larguraDoMaterialCm(b, materialId): number | undefined`.
- Dados: `useBuilding((s) => s.dim)` tem `alvenaria?: ResultadoAlvenaria` (`.paredes: ResultadoAlvenariaParede[]` com `id`, `nome`, `armada`, `panos`, `lados`, `vergas`, `quantitativo`…, `.desligamentos`, `.vigasMuro`, `.resumoBlocos`); `useBuilding((s) => s.sessao.modelo)` é o `BuildingModel`.
- `executarERecalcular(nome, params): Promise<boolean>` de `./Armadura` (executa o comando e atualiza o dimensionamento; já distingue os que refazem a análise). Comandos (todos `mcp: false`): `parede.modularAbertura { parede, abertura? }`, `verga.armadura { acao: 'editar' | 'copiar' | 'padrao' | 'limpar', abertura?, de?, para?, tipo?, armadura? }`, `parede.editar { id, tipo?, material? }`, `parede.criar { ..., tipo?, material? }`, `parede.daMascara { ..., tipo?, material? }`.

## A. `ArmaduraAlvenariaUI.tsx` — `AlvenariaDaParede({ id }: { id: string })`
Raiz `<div data-alv-parede={id}>`. `const dim = useBuilding((s) => s.dim)`, `const b = useBuilding((s) => s.sessao.modelo)`, `const r = dim?.alvenaria?.paredes.find((x) => x.id === id)`, `const w = b.paredes?.find((x) => x.id === id)`. Todos os `useState` antes do retorno antecipado `if (!r || !w || !dim?.alvenaria) return <Hint>Calcule o dimensionamento para ver a verificação da alvenaria.</Hint>;`. Estados: `sel: string` (chave do pano, padrão a da primeira linha de `linhasPanosAlv(r)`), `selV: string` (id da verga, padrão a primeira de `linhasVergas(r)`), `fv: FormVerga | null` (`null` = a da verga selecionada, `formDaVerga(linha.armadura)`).
1. `<h4>Verificação por pano</h4>` e `<p className="small" data-alv-situacao>` com `<Pill tone={rc.status === 'ok' ? 'ok' : 'bad'}>{rc.situacao}</Pill>` seguido de ` {rc.material} · {rc.armada} · {rc.panos} pano(s) · cumprimento mínimo {rc.cumprimentoMin} · {rc.blocos} peças` (`rc = resumoCartaoAlv(r)`; `rc.blocos` é `'—'` na alvenaria genérica).
2. Tabela `data-alv-panos` com as colunas **Trecho**, **Lance**, **Pano**, **s (m)**, **λ**, **Utilização compressão / tração / cisalhamento**, **Cumprimento**, **Pior combinação**, **Situação** e, só se `r.armada`, **Vertical**, **Horizontal** e **Origem** (antes de **Situação**). Uma `<tr data-chave={l.chave} aria-selected={sel === l.chave} className={l.status === 'fail' ? 'bad' : undefined} onClick={() => setSel(l.chave)}>` por `linhasPanosAlv(r)`; células `l.trecho`, `l.lance`, `l.pano + 1`, `l.intervalo`, `l.esbeltez`, `l.utilizacao`, `l.cumprimento`, `l.governa`, (`l.vertical`, `l.horizontal`, `l.origem`), `l.situacao`.
3. `<details data-alv-pontos>` com `<summary>Pontos fora das tensões-limite ({n})</summary>` (`n = linhasPontosAlv(r).length`) e tabela `data-alv-pontos-lista` com **Trecho**, **Lance**, **Ponto (s; z) m**, **Área (m²)**, **Limite excedido**, **Utilização**, **Combinação**. Sem linhas: `<p className="muted">Todos os pontos atendem.</p>`. `Hint` abaixo: "Fator de cumprimento: fração da área do pano que atende compressão, tração (10 % da compressão) e cisalhamento (opção 'Alvenaria: fator de cumprimento'); o que passa dela é aviso no relatório."
4. Se `linhasLadosAlv(r).length`: `<h4>Trechos curtos (pilares de alvenaria)</h4>` e tabela `data-alv-lados` com **Trecho**, **Lance**, **Comprimento (cm)**, **λ**, **Utilização**, **Combinação**, **Situação**.
5. Só `w.tipo === 'blocos'`: `<h4>Aberturas: modulação e verga</h4>`.
   - `Button` **"Ajustar aberturas à modulação"** (`disabled={!w.aberturas?.length}`) → `executarERecalcular('parede.modularAbertura', { parede: id })`.
   - Se `linhasVergas(r)` vazio: `<p className="muted">Sem aberturas nesta parede.</p>`. Senão tabela `data-alv-vergas` com **Tipo**, **Lance**, **Largura × altura**, **Modular**, **Necessária verga / contraverga**, **Verga**, **Contraverga**, **Estribo**, **Cortante V / VRd**, **Origem**, **Situação**; `<tr data-id={l.id} aria-selected={selV === l.id} className={l.status === 'fail' ? 'bad' : undefined} onClick={() => { setSelV(l.id); setFv(null); }}>` com `l.tipo`, `l.lance`, `l.dimensoes`, `l.modular`, `l.necessaria`, `l.verga`, `l.contraverga`, `l.estribo`, `l.cortante`, `l.origem`, `l.situacao`.
   - Editor `<div className="row wrap" data-alv-editor-verga>` (valores `fv ?? formDaVerga(linhaSel.armadura)`; cada campo faz `setFv({ ...atual, campo: valor })`): `NumField label="Verga: n" width={80}`, `Select label="Verga: φ"` (opções `BITOLAS_ALV_VERTICAL.map((p) => ({ v: p, label: String(p).replace('.', ',') }))`), `Select label="Estribo da verga: φ"` (opções `BITOLAS_ESTRIBO_VERGA`), `NumField label="Estribo da verga: s" unit="cm" width={90}` e, só se a abertura selecionada é janela, `NumField label="Contraverga: n" width={80}` e `Select label="Contraverga: φ"` (opções `BITOLAS_ALV_VERTICAL`). Botões:
     - **"Bloquear verga"** → `executarERecalcular('verga.armadura', paramsVergaEditar(selV, atual, linhaSel.tipo))`;
     - **"Copiar verga para as de mesmo tipo"** (`disabled` se `linhaSel.origem !== 'bloqueada'` ou `aberturasBlocosDoMesmoTipo(b, selV).length === 0`) → `executarERecalcular('verga.armadura', { acao: 'copiar', de: selV, para: aberturasBlocosDoMesmoTipo(b, selV) })`;
     - **"Definir como padrão do tipo"** → `executarERecalcular('verga.armadura', { acao: 'padrao', tipo: linhaSel.tipo, armadura: armaduraVergaDoForm(atual, linhaSel.tipo) })`;
     - **"Limpar verga"** → `executarERecalcular('verga.armadura', { acao: 'limpar', abertura: selV })`.
   - `Hint`: "Verga na canaleta grauteada, calculada pela faixa de parede acima da abertura; a verga bloqueada é verificada, não redimensionada. Em muro de subsolo não há aviso de biela."
   Se `w.tipo === 'alvenaria'`: no lugar do item 5 inteiro, `<Hint>Alvenaria genérica: não há verga calculada nem modulação.</Hint>`.
6. Só `r.quantitativo`: `<h4>Quantitativo de blocos</h4>` e tabela `data-alv-quant` com **Lance**, **Fiadas**, **Inteiros**, **Meios blocos**, **Peças de canto**, **Canaletas**, **Total**, **Área líquida (m²)** (uma linha por `linhasQuantitativo(r)`; a de total em `<b>`).
7. `<h4>Pilares em contato com o muro</h4>`: `linhasDesligamentos(dim.alvenaria, id)`; vazio: `<p className="muted">Nenhum pilar em contato com esta parede.</p>`; senão tabela `data-alv-desligamentos` com **Pilar**, **Pavimento**, **Laje junto ao pilar**, **Desligado do muro**. `Hint`: "O desligamento só vale com lajes de vigotas; com laje maciça lance o muro como elemento (aviso MURO_PILAR_MACICA)."
8. Se `linhasVigasMuro(dim.alvenaria, id).length`: `<h4>Vigas sobre o muro</h4>` e tabela `data-alv-vigas-muro` com **Viga**, **Papel**, **Seção**, **Armadura**, **Situação**.
9. `<h4>Mensagens</h4>` e `<ul data-alv-mensagens>` com `<li key={i}><b>{m.local}</b>: {m.texto}</li>` por `mensagensAlv(r)`; vazio: `<p className="muted">Sem mensagens.</p>`.
