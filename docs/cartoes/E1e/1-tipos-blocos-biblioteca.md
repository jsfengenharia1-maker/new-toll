## Layout e rótulos exatos de `AlvenariaGrupo({ b }: { b: BuildingModel })`
`<Group title={\`Alvenaria estrutural (${tipos.length})\`} open={tipos.length > 0 || blocos.length > 0}>` com `blocos = b.blocos ?? []` e `tipos = b.tiposAlvenaria ?? []`. Estados: `fb: FormBloco` (inicial `FORM_BLOCO_PADRAO`), `editB: string | null`, `ft: FormAlvenaria` (inicial `formDoTipo(undefined, 'blocos', blocos[0]?.id ?? '')`), `editT: string | null`, `msg: string`. Toda ação faz `const r = exec(...)`; se `r.ok`, limpa o formulário/edição e `setMsg('')`; senão `setMsg(r.erros[0]?.mensagem ?? 'Não foi possível.')`. A mensagem aparece em `<p className="hint bad" data-alv-msg>` quando não vazia.

### 1. Blocos
- `<h4>Blocos de concreto</h4>`.
- Tabela `data-alv-blocos` (só se `linhasBlocos(b).length`) com as colunas **Bloco**, **Dimensões**, **fbk (MPa)**, **Peça de canto**, **Tipos que usam** e uma última sem título; uma `<tr data-id={l.id}>` por linha com `l.nome` (`<b>`), `l.dimensoes`, `l.fbk`, `l.canto`, `l.emUso`; na última célula `<Button variant="ghost" aria-label={\`Editar bloco ${l.nome}\`} onClick={...}>editar</Button>` (carrega `formDoBloco(bloco)` em `fb` e `editB = l.id`) e `<Button variant="ghost" aria-label={\`Remover bloco ${l.nome}\`} onClick={() => ...exec('bloco.tipo', { id: l.id, remover: true })}>×</Button>`.
- Editor `<div className="row wrap" data-alv-editor-bloco>` com: `TextField label="Bloco: nome"`, `NumField label="Bloco: comprimento" unit="cm" width={90}`, `NumField label="Bloco: largura" unit="cm" width={90}`, `NumField label="Bloco: altura" unit="cm" width={90}`, `NumField label="Bloco: fbk" unit="MPa" width={90}` e `Select label="Bloco: peça de canto"` com opções `{ v: 'auto', label: 'automática' }, { v: 'sim', label: 'sempre' }, { v: 'nao', label: 'nunca' }`; cada campo grava `setFb({ ...fb, campo: valor })`. Botões: sem edição, `Button` **"Criar bloco"** → `exec('bloco.tipo', paramsBloco(fb))`; em edição, **"Salvar bloco"** → `exec('bloco.tipo', paramsBloco(fb, editB))` e **"Cancelar edição do bloco"** (volta `fb` ao padrão e `editB = null`).
- `Hint`: "Dimensões modulares com a junta (ex.: 40 × 15 × 20 cm). O meio bloco é metade do comprimento; a peça de canto é automática quando a largura não é metade do comprimento."
