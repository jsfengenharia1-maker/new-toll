# Contribuindo com o Statikos

Obrigado pelo interesse. Antes de abrir um pull request:

1. **Acordo de contribuição (CLA).** O primeiro PR pede a assinatura de um CLA individual simples (CLA Assistant no GitHub): você mantém os direitos sobre o que escreveu e concede ao projeto licença para distribuí-lo, inclusive sob outras licenças no futuro.
2. **Reconstrução limpa.** Nada de código, textos, ícones, nomes de comandos ou formatos proprietários de outros programas. Normas ABNT e métodos de livro-texto podem ser usados, com a fonte citada.
3. **Premissas visíveis.** Toda hipótese de cálculo nova fica editável no app, escrita no memorial e marcada "a confirmar" enquanto não tiver fonte conferida.
4. **Dados.** O repositório é público: nada de dados de clientes ou de obras reais.
5. **Validação.** `npm test`, `npx tsc -b`, `npm run lint`, `npm run build` e `npm run e2e` limpos.
6. **Marca.** O nome "Statikos" e a identidade visual não fazem parte da licença (ver `NOTICE`).

Comunicação em português.
